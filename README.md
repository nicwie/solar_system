# solar_system

To build, first `mkdir build`, `cd` into `build` and enter `cmake ..`.
After that, enter `make` and then you should see an executable.

This requires glew, opengl 3.3, cmake, assimp, and glfw.

In the program, use WASD to move, mouse to look around, and scroll to zoom.
Press Spacebar to enable wireframe mode.
Pressing '0' enables rotating around the earth. No other actions can be done here.
Pressing '1' returns the view to over the sun, and re-enables movement and look.
